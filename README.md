# Productivity Calculator

This Python program estimates your weekly productivity based on the number of tasks you completed today. It asks for your input, converts it into a number, and calculates how many tasks you would complete in a week if you continue at the same pace.

## How to Run
Open a terminal or command prompt in your project folder and run:

python app.py
# or
python3 app.py

## Example Output
Welcome! This is my Productivity Calculator.
How many tasks did you complete today? 5
If you keep this pace, you will complete about 35.0 tasks this week!

## Features
- User input
- Numeric conversion
- Weekly productivity calculation
- Clear printed output
